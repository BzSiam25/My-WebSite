# Project Overview

## Description

This project is a premium personal portfolio website designed to serve as a world-class digital identity. It showcases professional experience, technical expertise, research work, photography, and certifications.

## Key Features

- **Centralized Data Layer**: All content is driven by a local CMS within the `src/data` folder.
- **SEO & Performance First**: Built with Vite, optimizing images, and managing dynamic meta tags via `react-helmet-async`.
- **Advanced Integrations**: Features a live GitHub integration and an AI Assistant to interactively explore the portfolio data.
- **Premium Aesthetics**: Minimalist, high-performance UI utilizing shadcn/ui, Radix UI, and Framer Motion for sophisticated micro-interactions.

## Tech Stack

- **Framework**: React 18+ (Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Components**: shadcn/ui
- **State Management**: TanStack Query
- **Routing**: React Router v6
